# 王哥代下单

手机水果转盘，支持添加到 iPhone 主屏幕和离线使用。

## 发布到 GitHub Pages

将本目录里的文件上传到一个公开仓库根目录。在仓库 Settings → Pages 选择 Deploy from a branch，分支 main，目录 / (root)，保存。等待 GitHub 给出 HTTPS 网址。

普通转盘的水果选择和最近结果保存在当前浏览器。专属分享链接支持把每次抽选上传到 Supabase，管理者登录后查看自己名下的记录。

## 结果后台配置

1. 创建 Supabase 项目，运行上一级目录的 `后台数据库初始化.sql`。
2. 在 `config.js` 填写项目 URL 和 publishable key（或 legacy anon key）；绝对不要填写 service_role / secret key。
3. 在 Supabase Authentication → URL Configuration 将 Site URL 设为 `https://sheep33333333.github.io/wangge-fruit-wheel/admin.html`，并将同一个地址加入 Redirect URLs。
4. 打开 `admin.html`，用管理邮箱获取登录链接。首次登录会创建此网站的用户身份，它与 Supabase 控制台账号独立。
5. 管理页创建专属链接并发给对方。对方页面会提示每次结果将同步给分享者。普通网址不自动绑定管理者，也不会上传以往的记录。

每次点击转盘时生成唯一记录并开始上传；即使动画中退出页面，该次选择也尽早保存在本机待上传队列。离线恢复联网后重试，服务端按唯一 ID 去重。清理网站数据、始终不再联网或系统回收存储可能导致待上传记录无法恢复。

记录包含水果、当时的水果选项、手机抽选时间、服务器收到的时间及专属链接；不采集定位、通讯录或设备指纹。手机时间可能不准确，因此管理页同时显示北京时间的抽选时间与同步时间。

数据库启用 RLS。持有分享链接的人只能通过受限函数提交结果，不能读取历史；管理者仅能查询自己创建的链接及其记录。结果由客户端提交，用于日常分享，不能当作防作弊凭据。管理页支持逐页查看、按链接筛选、导出全部 CSV。

## iPhone 使用

1. 用 Safari 打开发布后的 HTTPS 网址，首次打开需要联网。
2. 点分享 → 添加到主屏幕；如果系统提供“作为网页 App 打开”，将其打开。
3. 主屏幕出现“王哥代下单”图标，以后可直接点击使用。
4. 首次完整加载并缓存后支持离线转盘；系统清理网站数据后需要重新联网打开一次。

局域网 HTTP 地址不能在 iPhone 上启用离线缓存，需要发布后的 HTTPS 地址。

页面已完成浏览器自动化检查；尚未在实体 iPhone 上验证。
